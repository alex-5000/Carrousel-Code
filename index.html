Langue de l’outil :

Générateur de code carrousel (FR / EN)

Travaillez une langue à la fois. Collez le code d’origine, modifiez les bannières, puis copiez le code final pour la publication.

Comment procéder (sans connaissance en code) :

  1. Choisissez une langue (Français ou English).
  2. Collez le code source dans la première zone et cliquez sur Charger dans le formulaire.
  3. Modifiez les champs (image, description, lien), ajoutez/supprimez des bannières ou glissez-déposez pour changer l'ordre.
  4. Vérifiez le résultat dans l’aperçu en bas (défilement auto + boutons précédent/suivant).
  5. Copiez le code final avec le bouton prévu et répétez pour l’autre langue.
